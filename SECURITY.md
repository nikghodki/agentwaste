# Security policy

agentwaste reads local agent transcripts, which can contain code, file paths
and secrets. It makes no network requests and never modifies those files.

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- through GitHub's **Report a vulnerability** button on the Security tab, or
- by email to nikghodki@gmail.com.

Examples: the shareable card leaking private data, agentwaste reading files
outside the chosen path, or any network access.

You'll get a reply within a week. Fixes are released as soon as they're ready,
with credit if you want it.

## Supported versions

Only the latest release gets security fixes.
