**agentwaste** reads the session logs your AI coding agent already keeps on your
computer, finds the patterns that burn tokens for nothing, and tells you what to
change. Usage trackers tell you *how much* you used. agentwaste tells you *why*,
and how much of it was avoidable.

```bash
uvx agentwaste
```

## Why it exists

AI coding agents spend far more than people expect, often for avoidable reasons:

- You step away for a few minutes, the prompt cache expires, and the next message
  re-sends the whole conversation at a higher price.
- The agent reads the same unchanged file again and again.
- One command dumps tens of thousands of tokens of output, which the agent then
  carries in every later message.
- A failing command is retried over and over.

If you pay per token, that's money. If you're on a subscription, it's the reason
you hit your usage limit early.

## What you get

- **A report** of where tokens went, how much was waste, and a grade from A to F.
- **A fix for each pattern**, with the worst examples (files, tools, models).
- **A shareable card** with aggregates only, safe to post.
- **JSON output** for scripts and dashboards.
