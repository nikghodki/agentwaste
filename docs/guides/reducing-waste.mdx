---
title: "Reducing waste"
description: "The habits that make the biggest difference."
---

In order of typical impact:

<AccordionGroup>
  <Accordion title="Compact or clear before a break">
    The prompt cache lasts 5 minutes. Running `/compact` before you step away means the
    context you come back to is small, so re-caching it is cheap. Use `/clear` when you
    switch tasks. See [Idle cache rebuild](/detectors/idle-cache-rebuild).
  </Accordion>
  <Accordion title="Check your proxy passes cache markers">
    If you reach Claude through a gateway, make sure prompt caching survives the hop.
    See [Uncached context](/detectors/uncached-context).
  </Accordion>
  <Accordion title="Keep tool output small">
    Limit command output with `head`, filter queries, and read big files in ranges.
    See [Huge result](/detectors/huge-result).
  </Accordion>
  <Accordion title="Write things down in CLAUDE.md">
    Facts the agent keeps re-reading, and fixes for errors it keeps hitting, belong in
    `CLAUDE.md`. See [Re-read](/detectors/reread) and [Error thrash](/detectors/error-thrash).
  </Accordion>
</AccordionGroup>

Re-run agentwaste a week later with `--days 7` to see whether it worked.
