## Usage trackers tell you how much. agentwaste tells you why.

<CardGrid>
  <Card title="Finds the waste" icon="magnifier">

  </Card>
  <Card title="Tells you the fix" icon="approve-check">

## What it finds

On the author's own month of Claude Code use, **about a third of all input cost was
re-caching context after stepping away for more than five minutes.** Most people have
no idea it's happening.
