---
title: "Privacy"
description: "What agentwaste reads, and what leaves your machine."
---

- **Local only.** agentwaste reads transcript files on your computer and prints a
  report. It makes no network requests.
- **Read-only.** It never changes your logs or settings.
- **The card is safe to share.** It holds aggregates only: grade, percentages, token
  totals, session count and time span. No file paths, project names, commands or
  content. A test enforces this.
- **The report and JSON are for you.** They can include the names of files,
  projects, tools and models from your sessions.
- **No data in the repo.** The test suite uses synthetic transcripts only.
